# LaunchLint v0.3 — PDF Visual Design

## Page Layout
- **Page size**: A4 (210×297mm) default; Letter option via `brand.page_size`.
- **Margins**: 20mm all sides.
- **Typography**: Helvetica/Helvetica-Bold for body; accent color for headings and score.

## Cover Page
1. Agency logo at top center (max width 80mm, height constrained proportionally).
2. Report title (default: "Pre-Launch Audit Report").
3. Client name if provided.
4. Target URL / path.
5. Generated date/time.
6. Agency name and contact at bottom.

## Executive Summary
- Large score circle/number (0–100).
- Severity count badges: errors, warnings, info.
- One-sentence interpretation based on score:
  - 90–100: "Clean launch. Ship it."
  - 70–89: "No blockers, but review warnings."
  - 50–69: "Issues should be fixed before launch."
  - 0–49: "Significant blockers. Do not launch."

## Findings Section
- Grouped by severity: ERROR → WARN → INFO.
- Each finding as a card:
  - Severity badge + check name.
  - Message.
  - Location if present.
  - Suggestion if present.
- Cards use `KeepTogether` to avoid page breaks inside.

## Appendix
- Target, checks run, duration, final URL, content type, size.
- "Generated by LaunchLint vX.Y.Y" footer line.

## Color Palette
- Accent: configurable hex (default `#2563EB`).
- Error: `#DC2626`
- Warning: `#D97706`
- Info: `#2563EB` (same as accent if no override)
- Text: `#1F2937`
- Muted: `#6B7280`
- Background: `#F9FAFB` for cards
