LaunchLint

Local-first pre-launch audit CLI for static sites. Catch SEO, broken links, accessibility, and config issues before launch.

MIT Python 3.10+ No account CI-ready v0.1.0

Install

uv tool install git+https://github.com/chemico0531/launchlint

Then verify with launchlint --doctor

Example output

$ launchlint https://example.com

  No blockers, but review warnings before launch.

What it checks

  • seo — title, meta description, h1, canonical, OG tags, JSON-LD
  • links — HTTP 4xx/5xx on internal + outbound (HEAD + GET fallback)
  • a11y — html lang, image alt, heading hierarchy, form labels, viewport
  • config — robots.txt, sitemap.xml, sitemap reference in robots

Why not Lighthouse?

Lighthouse is great. But it's online, slow, and noisy. Screaming Frog costs $259/year. Most "audit tools" are SaaS dashboards you can't run in CI. LaunchLint is local, instant, and designed to gate PRs.

CI integration

  - name: LaunchLint audit
    run: |
      pip install --user git+https://github.com/chemico0531/launchlint
      launchlint https://staging.yoursite.com \
        --fail-on error --json > ll.json || true
  - name: Show report
    run: cat ll.json
